# 게시글 작성 규칙

게시판은 최신순, 10개씩 페이지로 보여 줍니다.

| 탭 | 범위 | 폴더 (admissions-2026/ 기준) | 주기 | 파일·slug | 다루는 기간 |
|---|---|---|---|---|---|
| 학교 소식 | 학교 전체 | `posts/kyungmin/` | 매일 | `YYYY-MM-DD` (게시일) | 전날 하루 |
| 전문대 동향 | 학교 전체 | `posts/colleges/` | 매주 월요일 | `YYYY-MM-DD` (월요일 날짜) | 지난주 월~일, 수도권 위주 |
| 산업 현황 | 지능형소프트웨어과만 | `depts/software/posts/industry/` | 매주 월요일 | `YYYY-MM-DD` (월요일 날짜) | 지난주 월~일 |

경민대 학과 목록과 2027 수시 1차 지원현황은 `school/susi1-2027.json`, 학과별 비교 학교는 `depts/<학과>/ratios.json`에 있습니다.

## 글 추가 절차

1. `<폴더>/<slug>.md` 작성 (마크다운).
2. 같은 폴더 `index.json` 배열 **맨 앞**에 항목 추가:

```json
{
 "slug": "2026-10-05",
 "date": "2026-10-05",
 "title": "제목",
 "summary": "목록에 보일 한두 줄 요약",
 "tags": ["태그"],
 "file": "2026-10-05.md"
}
```

3. 같은 slug가 이미 있으면 새로 만들지 않습니다(중복 방지).

## 작성 원칙

- **사실만, 출처와 함께.** 모든 항목에 원문 링크를 답니다. 원문에서 직접 확인한 수치만 씁니다. 확인되지 않거나 기사끼리 서로 맞지 않으면 쓰지 않습니다.
- 해석·시사점은 별도 절로 나누고 “해석”이라고 밝힙니다.
- 중요한 부분: `<span class="alert">**강조**</span>` (빨간색). 한 글에 3~5곳 이내.
- 굵게 표시가 괄호·%로 끝나고 바로 한글이 이어지면 마크다운이 깨지므로 `<b>…</b>`를 씁니다.
- 출처 묶음은 `<div class="sources">` … `</div>`로 감싸고 앞뒤에 빈 줄을 둡니다.
- 다른 화면 링크: 학교 전체 `school.html`, 학과 분석 `admissions-dashboard.html?dept=<학과 id>` (지능형소프트웨어과는 `dept=` 생략).
- 해당 기간에 새 소식이 없으면 글을 만들지 않습니다.

## 게시판별 출처와 관점

**학교 소식** — 경민대학교를 다룬 **외부 언론 기사만** 씁니다(학교 홈페이지 공지·경민뉴스는 쓰지 않음). WebSearch로 “경민대학교”, “경민대” 기사를 찾고 원문에서 날짜와 내용을 확인합니다. 같은 행사를 다룬 여러 기사는 하나로 묶습니다. 학과 관련 기사는 학과명을 제목에 밝힙니다.

**전문대 동향 (학교 전체)** — 수도권 전문대의 입시 일정·경쟁률, 학과 개편·정원·신설, 재정지원사업(혁신지원·RISE 등) 선정, 교육부·한국전문대학교육협의회 정책. 특히 경민대에서 2027 수시 1차 지원자가 줄어든 학과(`school/susi1-2027.json`에서 `applied < prevApplied`)와 같은 계열의 다른 학교 움직임을 우선 다루고, “경민대 대비”로 정리합니다.

**산업 현황 (지능형소프트웨어과)** — SW·AI 채용 시장, 정부 정책(과기정통부·고용노동부·교육부), 공공 SW 수요, 국방·공공안전 AI, 경기 북부 지역 산업. 마지막 절에 “경민대 지능형소프트웨어과에 주는 시사점(해석)”.

글 주소: `kyungmin.html?post=<slug>`, `colleges.html?post=<slug>`, `industry.html?post=<slug>`
